# EVERLUMEN // NEUROGLASS design system

## Art direction
A speculative blacklight control surface: prismatic geometry, smoked glass, neon edge-lighting, glitch traces, fine grid scaffolding and luminous organic sigils. The intent is a system console with tactile, adorable micro-controls—not a copy of standard cyberpunk terminal themes.

## Shape and motion
- Main rail: radius 20, compact option 54 px high.
- Workspace capsules use brighter fill for active state and acid border for focused state.
- Decoration favors fast easing rather than persistent, distracting motion.
- Glass and scanlines are optional. Do not use color as the only state cue.

## Accessibility / performance
Keep foreground text high contrast. Keep outlines visible. Turn off blur and glow when needed. The current shell exposes display settings live, but does not yet persist them to disk.
